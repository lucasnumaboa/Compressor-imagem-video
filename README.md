# Compressor Manero

Um aplicativo web moderno para compressão de imagens e vídeos, utilizando tecnologias web avançadas.

## Demo

Acesse a demonstração online: [https://compressor.manerostream.com.br/](https://compressor.manerostream.com.br/)

## Funcionalidades

- **Compressão de Imagens**: Reduz o tamanho de arquivos de imagem mantendo boa qualidade visual
- **Compressão de Vídeos**: Comprime vídeos utilizando FFmpeg WebAssembly
- **Interface Amigável**: Design moderno e responsivo para todos os dispositivos
- **Processamento Local**: Toda compressão é feita no navegador, sem envio de arquivos para servidores

## Tecnologias Utilizadas

- HTML5, CSS3 e JavaScript moderno
- FFmpeg WebAssembly para compressão de vídeo
- Canvas API para compressão de imagem
- Vite como bundler e servidor de desenvolvimento

## Como Executar

1. Clone este repositório:
   ```
   git clone https://github.com/seu-usuario/compressor-manero.git
   cd compressor-manero/compressor-web
   ```

2. Instale as dependências:
   ```
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```
   npm run dev
   ```

4. Acesse o aplicativo em seu navegador:
   ```
   http://localhost:5200
   ```

## Requisitos

- Node.js 14.0 ou superior
- Navegador moderno com suporte a WebAssembly
